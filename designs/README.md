# Designs

UI mockups for Aimo Copilot: 9 screens, each in desktop/tablet and mobile layouts.

- [mockups/index.html](mockups/index.html): all screens on one page. One file per screen is in [mockups/screens](mockups/screens).
- [system/index.html](system/index.html): design system page.
- [posthog/DESIGN.md](posthog/DESIGN.md): the PostHog design spec we follow, from `npx getdesign@latest add posthog`.
- [system/REFERENCE.md](system/REFERENCE.md): what we add on top of it.

Open the HTML files in a browser. To rebuild after editing `mockups/src/`, run `designs/mockups/build.sh` (needs Node).
